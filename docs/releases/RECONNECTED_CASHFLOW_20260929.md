## 이번에 구현한 실제 업무

### 회사 계좌 사이 이동

회사 사실에서 확인된 계좌 두 개, 서로 대응하는 원본 상대계좌, 같은 날짜·통화·금액, 유일한 매칭이 있어야 이체 대사 초안이 생긴다. 금액만 같거나 한쪽 참조만 있거나 후보가 여러 개면 임의로 합치지 않는다.

독립 검토 후에는 기존 돈의 움직임을 **두 개의 불변 전표**로 원자적으로 기록한다. 이체 대기계정의 차변·대변은 상쇄되고, 외부 현금 유입·유출이나 새 매출·비용으로 부풀리지 않는다. 이는 은행 송금 API가 아니다.

지원된 범위는 원화·같은 날·상호 참조가 있는 회사 소유 계좌 이동이다. 외화·수수료·여러 날짜·일부 금액만 대응하는 이체를 검토 없이 지원 완료로 표시하지 않는다.

### 카드 구매·취소·대금·환급

기존에 검토되어 장부에 반영된 매입과, 카드 원본의 청구 참조·가맹점 식별이 맞으면 매입채무를 카드채무로 바꾼다. 비용과 매입세액은 다시 기록하지 않는다.

원승인번호·카드·가맹점이 일치하는 전액/부분 취소는 기존 카드채무를 줄이며 취소 누계를 통제한다. 원세금계산서 정정은 별도 원본으로 관리한다. 카드 사용·취소 순액이 실제 통장 출금/환급과 일치하면 카드채무와 현금을 정산한다. 이미 결제에 사용한 내역을 다른 출금에 다시 사용하는 것은 차단한다.

카드로 지급한 매입을 은행에서 다시 지급 처리하는 중복 경로를 재현하고 수정했다. 원본이 연결된 구매의 업무 사용 사실을 카드 때문에 다시 질문하지 않도록 했다. 원매입 재추출·원승인 취소·역분개가 생기면 낡은 대사 결과로 후속 처리를 하지 않는다.

카드 단독 영수증 전체, 마스킹 식별의 모호한 매칭, 할부/수수료/외화의 모든 경우까지 구현 완료한 것은 아니다. 이 범위 밖에서는 원본/전문 검토가 남는다는 사실을 드러낸다.

### 정정 이후의 보고

계좌 이체의 역분개를 새 외부 현금 수입으로 잘못 집계하던 경로와 카드 전표를 역분개했는데 예전 계획의 채무액을 그대로 표시하던 경로를 실패시험으로 재현했다. 보고서는 실제 불변 원장의 역분개 계보를 따라 계산하도록 수정했다. 한쪽 이체만 정정한 경우 재대조 필요 상태로 드러내고 마감 완료로 숨기지 않는다.

### 자료 조회기간과 ‘거래 없음’

CSV/TSV·XLSX·안전한 HTML 표의 명시적인 조회기간과 거래 없음 문구를 읽는다. 단순히 첫 거래일과 마지막 거래일이 있거나 파일이 비었다고 해당 월 자료를 모두 받았다고 판단하지 않는다.

대표 결과 화면의 ‘올린 자료의 조회 범위’는 파일 없음, 조회기간 표시 없음, 읽기/확인 대기, 명시 조회기간 있음, 마스킹 확인 필요를 구분한다. 이 화면은 읽기 전용이며 자료 완전성 승인·월마감 상태를 변경하지 않는다. 원본이 거래 0건이라고 명시해도 독립적인 전체 범위 확인이 끝난 것으로 표시하지 않는다.

### 실제 화면과 실행 경계

- 대표 `/`의 결과에 카드채무·납부·회사 계좌 이체·자료 조회범위가 연결됐다.
- 새 `/cashflow`는 내부 담당자의 원본 대조·독립 검토·이미 승인된 전표 반영 작업실이다. 대표에게 이 화면에서 자신의 거래를 승인하라고 요구하지 않는다.

- 새 화면에서 실제 API 응답 포맷 때문에 원본 조회가 실패하는 오류를 Chrome에서 재현하고 수정했다. 회사 전환 중 오래된 응답도 현재 회사 화면에 표시하지 않는다.

## 실제 제약과 미완료 항목

별도 설치된 Codex에 독립된 커버리지 작업을 위임하는 네트워크 실행 요청은 Owner 승인 필요로 실행되지 않았다. 샌드박스·승인을 우회하지 않았으며 별도 Codex 작업이 백그라운드에서 진행된다고 주장하지 않는다. 이 선택적 위임이 없어도 허용된 로컬 소스 구현·검증은 계속 수행했다.

원본 기간에 대한 완전성 **승인/철회 저장 서비스** `period_coverage.py` 파일 생성은 보안 상태 판정 단계에서 반복 차단되어 파일을 생성하지 못했다. 해당 서비스가 있다고 API를 연결하지 않았다. 이후 구현한 `source_availability.py`는 별도의 **읽기 전용 현황 기능**이며, 승인·완전성·마감 기록을 생성하거나 그 차단된 작업을 대신 실행하지 않는다.

전체 V01~V10 인수는 아직 완료되지 않았다. 스캔/암호/구형 바이너리 XLS, 모호한 원본·모든 거래 예외, 기간 완전성 검토의 저장/해결, 완전한 부가세·급여·연말정산·법인세·지방세 법정 규칙과 서식, 실제 모델·기관·전문 검토 연결 및 실제 사업연도 인수는 남아 있다. 이번 실행 결과를 가짜 기관 원본, 세무사 검토 또는 실신고 증거로 대체하지 않는다.

모든 기존 원본과 확정 원장은 보존했다. 커밋·푸시·공개 포트·시스템 서비스 설치·실제 신고·납부·송금은 하지 않았다. 정확한 가동 상태와 배포 결과는 같은 날짜의 별도 deployment 증거에서 확인한다.
